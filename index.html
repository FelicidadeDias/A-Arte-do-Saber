Uma proposta de formação centrada na aprendizagem e na preparação para novas oportunidades.

Conteúdos apresentados de forma directa, com atenção à aplicação dos conhecimentos.

Comece hoje

Faça a sua pré-inscrição.

Preencha os seus dados e escolha a formação. O website prepara uma mensagem para enviar à equipa da Arte do Saber pelo WhatsApp; a direcção fará o registo manual nos arquivos da instituição.

  • Peça informações sobre vagas e próximas turmas.
  • Consulte os horários disponíveis.
  • Solicite uma marcação para atendimento presencial.
  • Peça esclarecimentos sobre inscrição, mensalidades e formas de pagamento.

Pedido de inscrição e atendimento

Os dados serão incluídos na mensagem que abrirá no WhatsApp. Não são guardados numa base de dados online. A inscrição só fica confirmada após validação pelo centro.

Ao continuar, o WhatsApp será aberto com a mensagem preenchida. Este formulário não guarda os dados no website nem confirma automaticamente uma matrícula. Evite enviar fotografias ou números de documentos pessoais nesta primeira etapa.
Simples e directo

Como funciona a pré-inscrição?

O primeiro contacto é feito pelo WhatsApp. A equipa da instituição recebe os dados e dá seguimento ao processo de forma manual.

1

Preencha o formulário

Indique o seu nome, contacto, formação pretendida e os dados necessários para a equipa compreender o seu pedido.

2

Envie pelo WhatsApp

O website prepara uma mensagem com as informações preenchidas e abre o WhatsApp para que possa enviá-la directamente à instituição.

3

A instituição confirma

A direcção recebe o pedido, verifica as vagas e os dados e regista manualmente a informação nos seus próprios arquivos.

Transparência: este website não possui uma base de dados online e não guarda os dados dos candidatos. As informações só são encaminhadas quando o próprio interessado envia a mensagem pelo WhatsApp. A confirmação da inscrição é feita directamente pela instituição.
